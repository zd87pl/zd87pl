## What I keep coming back to

- **Context is the real work**: when agents write the code, deciding what they should know is the scarce skill
- **Agents need infrastructure**: memory, permissions and scheduling
- **Honest evaluation**: labeling what can and can't count as evidence
- **Local-first, privacy-preserving AI**
